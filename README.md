# 🌦️ Weather Forecast App

A simple and user-friendly **Weather Forecast Mobile App UI** designed to provide users with current weather information, forecasts, and weather-related details in a clean and modern interface.

## 📱 Project Overview

This project focuses on designing a weather application that allows users to quickly check the current weather conditions and upcoming forecasts.

The UI is designed with a simple layout, attractive colors, clear weather icons, and easy navigation.

## ✨ Features

- 🌡️ Current temperature display
- ☁️ Current weather condition
- 📍 Location-based weather information
- 📅 Daily weather forecast
- 🌧️ Hourly weather forecast
- 💧 Humidity information
- 💨 Wind speed details
- 🌅 Sunrise and sunset information
- 🔍 Search for different locations
- 🏠 Simple bottom navigation
- 📱 Mobile-friendly interface

## 🎨 UI Screens

The design includes:

1. **Welcome / Get Started Screen**
2. **Current Weather Screen**
3. **Location Search Screen**
4. **Weather Forecast Screen**

## 🛠️ Design Tool

- **Figma** – UI/UX Design
- **Mobile App Design**
- **Prototype & Wireframing**

## 🎯 Design Goals

- Keep the interface simple and clean
- Make weather information easy to understand
- Provide quick access to important weather details
- Use attractive colors and weather illustrations
- Create a smooth and user-friendly experience

## 📌 Purpose

This project was created as a **UI/UX design project** to practice mobile application design, visual hierarchy, navigation, color selection, and user experience.
